# Learn Code App

A Full Stack Development learning platform for beginners.

## Features

- HTML Lessons
- CSS Lessons
- JavaScript Lessons
- React Lessons
- Node.js Lessons
- Express.js Lessons
- MongoDB Lessons
- Progress Tracking
- Interactive UI
- Responsive Design

- HTML5
- CSS3
- JavaScript
- JSON
